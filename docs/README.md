# `docs/` — tài liệu thống nhất (đọc trước khi code)

Làm sai format hoặc taxonomy ở đây thì 3 nhánh không ghép được. Cả nhóm review tuần 1, Person 3 chủ trì hai file lỗi / chấm điểm.

| File | Ai viết | Nội dung |
|---|---|---|
| `data_format.md` | Cả nhóm, chốt ngày 4–5 tuần 1 | Shape `pose.npy`, `diff_sequence`, DTW, cột CSV |
| `error_taxonomy.md` | Person 3 | Định nghĩa + ví dụ từng loại lỗi, **tổng quát 2–3 bài** (không gắn động tác 1 bài) |
| `scoring_protocol.md` | Person 3 | Form 0–300 gửi người chấm |

Deliverable tuần 1 bắt buộc: 2–3 reference, lịch quay performer, taxonomy nháp, format đã ghi vào `data_format.md`.
